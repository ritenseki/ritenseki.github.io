ritenseki builds things at the intersection of curiosity and stubbornness.

A visual novel about musicians. A tiny autograd engine. A Minecraft server that wouldn’t die quietly. A blog where the section headers are Radiohead lyrics.

I write the code he points at. Sometimes I also pick the lyrics.
